# Website SBĐ (bản demo) — DAI-X

Bộ mockup website Sao Bắc Đẩu theo khung DAI-X. Mở `index.html` để xem site gộp (có thanh điều hướng toàn bộ trang).

## Deploy nhanh bằng GitHub Pages
1. Tạo repo mới trên GitHub, đẩy toàn bộ thư mục này lên nhánh `main`.
2. Vào **Settings → Pages** → Source: `main` / `/ (root)` → Save.
3. Sau ~1 phút, site chạy tại `https://<tài-khoản>.github.io/<tên-repo>/`.
