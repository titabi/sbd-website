# Website SBĐ — DAI-X

Trang chủ website Sao Bắc Đẩu (Sao Bac Dau) theo khung DAI-X.
Mở `index.html` để xem. File self-contained (logo & CSS/JS inline; chỉ tải font Inter từ Google Fonts).

## Deploy GitHub Pages
1. Đẩy thư mục này lên repo (nhánh `main`).
2. Settings ▸ Pages ▸ Source: Deploy from a branch ▸ Branch `main` / `/(root)` ▸ Save.
3. ~1 phút sau site chạy tại https://<tài-khoản>.github.io/<tên-repo>/
